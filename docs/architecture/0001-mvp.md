# ADR 0001: MVP vertical slice

Status: Accepted

## Decision

Ship one mobile-first communication experience and an ASP.NET Core REST API.
The first runnable slice uses an in-memory repository and a notification outbox
to avoid hiding product decisions behind infrastructure work.

## Included

- Development login and role-bearing member profile
- Church overview
- Groups
- Announcements with pinned state
- Relevant events and RSVP
- Volunteer positions and signups
- In-app notifications
- Responsive administrator overview

## Deferred before beta

- PostgreSQL repository and migrations
- JWT issuing/validation, password hashing, Google and Apple OAuth
- Group membership authorization policies
- Push/email delivery workers, queues, retries, and idempotency
- Blob attachments, Redis caching, rate limiting, audit persistence
- React Native application

These are deliberate beta gates, not optional production hardening.
